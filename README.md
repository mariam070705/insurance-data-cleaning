 Insurance Data Cleaning

 Project Overview
This project focuses on cleaning and preprocessing an insurance dataset using Python. The goal is to improve data quality by handling missing values, removing duplicates, detecting outliers, and preparing the dataset for further analysis or machine learning.

 Objectives
- Understand the dataset structure
- Handle missing values
- Remove duplicate records
- Detect and treat outliers
- Standardize and clean the data
- Prepare the dataset for analysis


**Dataset:** Insurance Dataset

The dataset contains insurance-related information used for data cleaning and preprocessing.

 Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

 Data Cleaning Steps
- Imported the dataset
- Explored the dataset
- Checked data types
- Identified missing values
- Removed duplicate records
- Detected and handled outliers
- Renamed columns where necessary
- Cleaned inconsistent values
- Exported the cleaned dataset
